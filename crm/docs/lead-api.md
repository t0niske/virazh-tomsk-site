# Контракт приёма заявок

Единая точка, куда отправляют заявки **все** формы сайта virazh-tomsk.ru (assets/js/site.js) и любые будущие лендинги.
Реализует сессия «Заявки и админка», использует сессия «Дизайн и новый сайт».

## Адреса

- `POST /api/lead` — основной адрес.
- `POST /send-form.php` — тот же обработчик по старому адресу (так отправляли формы старый сайт и первые версии нового).

## Запрос

`multipart/form-data` или `application/x-www-form-urlencoded`.

| Поле | Обязательно | Значения |
|---|---|---|
| `name` | нет | до 100 символов; пусто — сервер сохранит «Без имени» (форма «только телефон») |
| `phone` | да | любой ввод; сервер приводит к `+7XXXXXXXXXX`, принимает только российские мобильные |
| `consent` | да | `1` / `on` — согласие на обработку персональных данных |
| `service` | нет | название услуги, например «Категория B (АКПП)» |
| `page_url` | нет | адрес страницы, с которой отправлена форма |
| `contact_time` | нет | `now` (по умолчанию), `morning`, `day`, `evening` |
| `channel` | нет | `call` (по умолчанию) или `max` |
| `utm_source`, `utm_medium`, `utm_campaign`, `utm_content`, `utm_term`, `yclid` | нет | метки рекламы |
| `visitor_id`, `visit_id` | нет | cookie `sd_vid` и `sd_sid` счётчика сайта (`docs/visits-api.md`), 8–40 символов `[A-Za-z0-9_-]` — связь заявки с заходами. Если полей нет, сервер берёт эти cookie из запроса |
| `chat_id` | нет | номер окна чат-бота (`docs/chat-api.md`), 16–40 символов `[A-Za-z0-9_-]` — заявка «Позвоните мне» из чата связывается с перепиской |
| `smart-token` | если капча включена | токен Яндекс SmartCaptcha |
| `website` | — | ловушка для ботов: поле скрыто от людей, должно быть пустым |

## Ответ

Всегда JSON. Код `200` при успехе, `422` при ошибке в данных, `429` при слишком частых отправках, `500` при сбое.

```json
{
  "success": true,
  "lead_id": 148,
  "title": "Заявка принята!",
  "message": "Позвоним в ближайшее рабочее время с номера +7 (983) 234-56-56 — сохраните его, чтобы не пропустить звонок.",
  "max_link": "https://max.ru/..."
}
```

```json
{
  "success": false,
  "message": "Проверьте номер телефона.",
  "errors": { "phone": "Нужен российский мобильный номер." }
}
```

- `message` формирует сервер: «в ближайшее рабочее время», с пятницы 17:30 до конца воскресенья — «в понедельник»,
  если клиент выбрал время — «сегодня после 17:00» и т. п. Тексты меняются в настройках админки. Форма показывает его как есть.
- `max_link` есть, только если бот MAX настроен. Форма показывает кнопку «Написать в MAX» только при наличии ссылки.
