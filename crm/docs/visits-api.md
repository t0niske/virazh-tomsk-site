# Контракт: заходы на сайт (статистика визитов в /crm)

> Перенесено с «Сто дорог». У Виража счётчик — `assets/js/visits.js` (на всех страницах, только на боевом домене и локально),
> приём — `crm/app/src/Visits/`. Таблица «Кто делает» ниже — про проект «Сто дорог».

Решение заказчика 13.11.2026: руководитель видит в админке, кто и откуда заходил, сколько пробыл, что делал,
человек это или бот, была ли с захода заявка. Свой счётчик на нашем сервере. Яндекс Метрика остаётся
для записей экрана (Вебвизор).

| Часть | Кто делает | Файлы |
|---|---|---|
| Счётчик на страницах, связка формы с заходом, политика и плашка cookie | «Дизайн и новый сайт» | `public/assets/js/site.js`, `templates/site/partials/lead-form.php`, `content/policy.php`, `tests/site/` |
| Приём данных, хранение, источники, боты, очистка, админка | «Заявки и админка» | `app/src/Visits/` (новая папка, зона «Заявки»), `app/src/Leads/Http/Routes.php`, `database/migrations/`, `cron/`, `app/src/Crm/`, `templates/crm/`, `tests/leads/` |

## Идентификаторы

Ставит и продлевает счётчик (JavaScript), сервер только читает.

| Cookie | Что | Срок |
|---|---|---|
| `sd_vid` | посетитель: 22 символа `[A-Za-z0-9_-]`, случайные | 12 месяцев, продлевается при каждом заходе |
| `sd_sid` | заход (визит) | 30 минут бездействия; новый заход и при смене источника (другие UTM-метки, переход из поиска или с другого сайта) |

Оба cookie: `path=/`, `SameSite=Lax`, `Secure` на https. Без cookie (заблокированы) счётчик всё равно шлёт данные
с идентификаторами только на эту страницу — заход будет без истории.

У каждого просмотра страницы свой `pid` (12 символов, случайные).

## Адрес

`POST /api/visit`. Тело — JSON, `Content-Type: text/plain;charset=UTF-8` (так шлёт `navigator.sendBeacon`, без
предварительного запроса). Ответ — `204` без тела всегда, даже при ошибке в данных (счётчику нечего с ней делать).

- Не больше 8 КБ на запрос, не больше 120 запросов в минуту с одного IP — лишнее молча отбрасывать.
- Поля сверх контракта игнорировать, строки обрезать до указанной длины.
- Запрос с чужим `Origin` / `Referer` (не наш домен) — отбрасывать.

## Сообщения

Каждый запрос — один объект или массив объектов (пачка). Общие поля: `t` (тип), `vid`, `sid`, `pid`, `ts` (время
на устройстве, мс от начала просмотра страницы — для порядка событий; время на сервере ставит сервер).

### `t: "view"` — открыта страница

| Поле | Что |
|---|---|
| `path` | адрес страницы без домена, до 300 символов. Строка запроса — только `utm_*`, `yclid`, `gclid`, остальное счётчик вырезает |
| `title` | заголовок страницы, до 200 |
| `ref` | откуда пришёл (`document.referrer`): для чужих сайтов — только `https://хост/путь` без строки запроса; свой сайт — `""`, до 300 |
| `utm` | объект `utm_source`, `utm_medium`, `utm_campaign`, `utm_content`, `utm_term`, `yclid`, `gclid` — что есть, по 200 |
| `screen` | `"390x844"` |
| `lang` | `navigator.language`, до 20 |
| `tz` | часовой пояс устройства, `"Asia/Tomsk"`, до 50 |
| `touch` | `true` — сенсорный экран |
| `wd` | `true` — `navigator.webdriver` (браузер управляется программой) |
| `new` | `true` — cookie `sd_vid` только что создан |
| `ym` | ClientID Яндекс Метрики, если есть — для поиска записи в Вебвизоре, до 30 |

### `t: "event"` — действие

`name` и необязательный `data` (строка до 200):

| `name` | Когда | `data` |
|---|---|---|
| `tel` | нажал на номер телефона | номер `+79832345656` |
| `max` | нажал «Написать в MAX» | — |
| `vk` | перешёл во ВКонтакте | — |
| `map` | открыл карту на странице («Показать на карте») | — |
| `route` | нажал «Маршрут в Яндекс Картах» / «Как добраться» | адрес офиса |
| `form_view` | форма заявки показалась на экране | `id` формы |
| `form_start` | начал заполнять форму (первый ввод) — **значения полей не отправляются** | `id` формы |
| `form_error` | сервер вернул ошибку | код ответа |
| `lead` | заявка принята | номер заявки |
| `scroll` | дочитал до 25 / 50 / 75 / 100 % страницы | `"25"`… |
| `a11y` | включил версию для слабовидящих | — |
| `out` | ушёл по внешней ссылке | хост |
| `file` | открыл документ (PDF и т. п.) | путь |

### `t: "ping"` — страница открыта и видна

Раз в 30 секунд, пока вкладка на экране. По нему считаются «сейчас на сайте» (ping за последние 2 минуты).

### `t: "leave"` — ушёл со страницы или скрыл вкладку

| Поле | Что |
|---|---|
| `active` | сколько секунд страница была на экране (без времени в фоне) |
| `scroll` | наибольшая прочитанная доля, 0–100 |

`leave` может прийти несколько раз за просмотр (вкладку скрыли и вернули) — брать наибольшие значения.

## Связь с заявкой

Форма заявки отправляет в `POST /api/lead` (`docs/lead-api.md`) два новых необязательных поля:

| Поле | Значение |
|---|---|
| `visitor_id` | `sd_vid` |
| `visit_id` | `sd_sid` |

Счётчик добавляет их к отправке формы сам (`FormData`), в разметке формы полей нет. Если полей нет (форма ушла
без JavaScript), сервер может взять их из cookie `sd_vid` / `sd_sid` запроса. Сервер заявок сохраняет их у заявки. В карточке заявки — «Путь клиента»: все заходы этого `visitor_id`
до заявки и после. Кроме того, счётчик шлёт событие `lead` с номером заявки — на случай, если поля не дошли.

## Что считает сервер

**Источник захода** — по первому просмотру: `yclid` → «Яндекс Директ»; `gclid` → «Google Реклама»; `utm_*` → «Реклама:
utm_source»; `ref` — `yandex.*`/`ya.ru` поиск → «Поиск Яндекса», `google.*` → «Поиск Google», `yandex.*/maps` →
«Яндекс Карты», `2gis.*` → «2ГИС», `vk.com`/`vk.ru` → «ВКонтакте», `max.ru` → «MAX», `t.me` → «Telegram»,
другой хост → «Сайт: хост»; пусто → «Прямой заход».

Поисковый запрос сайту не передаётся (Яндекс и Google не отдают его с 2015–2017). Запросы — этап 2: отдельная
вкладка из API Яндекс Вебмастера и Google Search Console (по дням и страницам, не по людям), нужны ключи доступа
от владельца сайта.

**Человек или бот** — `human` / `suspect` / `bot` и список причин:
- `bot`: подпись браузера поискового робота или сервиса (`bot`, `crawl`, `spider`, `Yandex…`, `Googlebot`, `bingbot`,
  `HeadlessChrome`, `Lighthouse`, `curl`, `python` и т. п.); `wd: true`;
- `suspect`: больше 30 страниц за 5 минут; меньше 2 секунд на странице без единого действия; нет `ping` и `leave`
  вовсе; IP из подсетей хостингов и облаков (необязательно, список можно добавить позже);
- остальное — `human`. В списке заходов боты по умолчанию скрыты.

**Номер захода** — какой по счёту заход у этого `visitor_id`, дата первого и прошлого захода.

**Устройство** — телефон / планшет / компьютер, браузер и система по подписи браузера. **Город** — этап 2 (нужна
база GeoIP без внешних запросов).

## Админка (зона «Заявки»)

Видят роли руководителя и менеджера (в заходах есть IP — это персональные данные).

1. **Заходы** — список: время, источник, страница входа, сколько страниц и минут, устройство, № захода,
   метки «Заявка №…» и «бот». Фильтры: период, источник, люди / боты / все, только с заявкой, только с нажатием
   на телефон.
2. **Заход** — путь по страницам со временем на каждой и действиями между ними; все заходы этого посетителя;
   ClientID Метрики для Вебвизора, если есть.
3. **Карточка заявки** — блок «Путь клиента»: первый источник, сколько дней от первого захода до заявки, все заходы.
4. **Сводка** (в отчётах): за день / неделю / месяц — люди, заходы, заявки, конверсия; источники; страницы входа;
   страницы, после которых чаще оставляют заявку; где чаще уходят; нажатия на телефон и MAX; «сейчас на сайте».
5. **Оповещение** (настройка, по умолчанию выключено): в Telegram «клиент по заявке №… снова на сайте, смотрит …»
   — без имени, телефона и IP, как остальные оповещения.

## Хранение

- Заходы без заявки и их события — **3 месяца**, затем удаляются (cron). Посетитель без заходов и без заявок — тоже.
- Заходы, связанные с заявкой, — сколько хранится заявка (заявки без записи — 12 месяцев).
- IP хранится только у захода и удаляется вместе с ним.
- Политика конфиденциальности дополнена: сайт сам собирает сведения о посещениях (`content/policy.php`).
