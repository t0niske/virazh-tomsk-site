# Авто-Вираж — новый сайт автошколы

Редизайн [virazh-tomsk.ru](https://virazh-tomsk.ru/) — автошкола «Авто-Вираж», Томск. Сейчас здесь главная страница в стиле [cooleso.ru](https://cooleso.ru/) на фирменном красном цвете. Сначала сделана мобильная версия, десктоп собран на её основе.

## Что где лежит

| Путь | Что это |
|---|---|
| `index.html` | Главная страница. Вся вёрстка, стили и скрипты в одном файле, без сборки. |
| `img/` | Картинки: логотип, машины, инструкторы, фото. |
| `docs/strategy.html` | Аналитика: аудит старого сайта, путь пользователя, структура блоков, карта кнопок, SEO, карта сайта, метрики. |
| `archive/clean.html` | Альтернативный «чистый» вариант главной (без стиля cooleso) — для сравнения. |
| `.nojekyll` | Нужен, чтобы GitHub Pages отдавал файлы как есть. |

## Как посмотреть

Откройте `index.html` в браузере — сайт работает без сервера и сборки.

Заметки аналитика к каждому блоку показываются, если добавить к адресу `#notes`, например `index.html#notes`.

## Стиль

- Шрифт Montserrat (Black Italic, заглавные) для заголовков — близкая бесплатная замена шрифта Muzzard у cooleso; совпадает по характеру с логотипом «АвтоВираж».
- Цвета заданы переменными в начале `<style>` в `index.html` (`--red`, `--grey`, `--head` и др.). Чтобы перекрасить акцент, достаточно поменять `--red` и `--red-dark`.
- Приёмы cooleso: ключевые слова заголовков красным, серые карточки с бледными номерами 01–04, машина на фоне кольца, красная лента преимуществ, «Хочу учиться на этой!» у каждой машины, форма из одного поля и цветные кнопки мессенджеров.

## Что заменить перед запуском

- [ ] **Факты, которые расходятся между virazh-tomsk.ru и avto-virazh.ru:** год основания (2006 или 2007), 2 или 3 офиса (пр. Ленина, 94), входит ли экзамен ГИБДД в цену, коробка у Ковалёнка А. В., источник цифры «95% с первого раза».
- [ ] **Обещания, которые нужно подтвердить:** цена зафиксирована в договоре, бесплатная смена инструктора, пробное занятие на автодроме.
- [ ] **Данные-примеры:** расписание групп и число мест, даты внутреннего экзамена, часы работы офисов, «перезвоним за 15 минут».
- [ ] **Ссылки:** VK, Telegram, MAX, карточка 2ГИС (сейчас стоят заглушки `vk.com`, `t.me`, `max.ru`, `2gis.ru/tomsk`).
- [ ] **Стоковые фото с Unsplash** (`img/photo-*.jpg`) — заменить на свои: урок вождения, автодром, личный кабинет, выпускник с правами.
- [ ] **Фото инструкторов** — переснять всех в одном стиле.
- [ ] **Формы** — сейчас заявки никуда не отправляются. Подключить отправку (CRM, почта или Telegram-бот) и цели Яндекс Метрики.
- [ ] **Микроразметка** в конце `index.html` — дополнить реальными координатами и часами работы.

## Источники картинок

- Логотип, машины, фото Omoda C5 и мотоцикла — с сайтов автошколы (virazh-tomsk.ru, avto-virazh.ru).
- Фото инструкторов — с virazh-tomsk.ru.
- `img/photo-*.jpg` — Unsplash (бесплатная лицензия Unsplash), временные.
