# Авто-Вираж — новый сайт автошколы

Новый дизайн [virazh-tomsk.ru](https://virazh-tomsk.ru/) — автошкола «Авто-Вираж» (АНО ДПО «Авто-Вираж»), Томск и Новосибирск. Стиль [cooleso.ru](https://cooleso.ru/) на фирменном красном, сначала мобильная версия.

**Главное правило переноса: адреса не меняются.** Каждая страница старого сайта живёт по тому же адресу (без слэша на конце), PDF-документы и фото — по тем же путям. Так поисковики не теряют вес страниц. Подробно — в [docs/url-map.md](docs/url-map.md).

Предпросмотр: https://t0niske.github.io/virazh-tomsk-site/ (закрыт от индексации).

## Что где лежит

| Путь | Что это |
|---|---|
| `src/pages/` | Страницы. Путь файла = адрес на сайте: `src/pages/obuchenie/kategoriya-b-akpp.html` → `/obuchenie/kategoriya-b-akpp`. |
| `src/partials/` | Общие блоки: шапка, подвал, формы, карточки инструкторов, автопарк, цены, меню раздела «Сведения». |
| `src/layout.html` | Каркас страницы: `<head>`, метатеги, подключение стилей и скриптов. |
| `assets/` | Стили (`site.css` — общий стиль, `pages.css` — внутренние страницы и версия для слабовидящих), шрифты Montserrat (свои, без Google Fonts), `site.js`. |
| `img/` | Картинки нового дизайна (`img/art/` — предметы первого экрана и 3D-знак). |
| `media/`, `images/` | Документы и фото **по путям старого сайта** — не переименовывать. |
| `tools/build.pl` | Сборка сайта в папку `_site`. |
| `tools/check.pl` | Проверка сборки: все старые адреса на месте, нет битых ссылок, у страниц есть title, description, canonical и один H1. |
| `tools/old-urls.txt` | Список адресов старого сайта, которые обязаны работать. |
| `tools/import-old.pl` | Переносит текст страницы старого сайта в фрагмент `src/pages`. |
| `docs/url-map.md` | Карта переноса адресов и что найдено на старом сайте. |
| `docs/compliance.md` | Требования к сайту образовательной организации и что сделано. |
| `docs/strategy.html` | Аналитика: путь пользователя, структура, SEO. |

## Сборка

Нужен Perl (есть в Git Bash на Windows, на Linux и macOS — из коробки).

```bash
perl tools/build.pl
```

```bash
perl tools/check.pl
```

Готовый сайт — в `_site`. Предпросмотр для GitHub Pages собирается так (адреса с префиксом, всё закрыто от индексации):

```bash
perl tools/build.pl --preview --base=/virazh-tomsk-site --out=_preview
```

GitHub Pages обновляется сам при каждом push в `main` (`.github/workflows/pages.yml`).

## Как устроена страница

В начале файла — метаданные, дальше — содержимое `<main>`:

```html
<!--meta
title: Заголовок вкладки и сниппета
description: Описание для поисковика
noindex: 1                  (необязательно — закрыть от индексации)
redirect: /novyj-adres      (необязательно — 301 на другой адрес)
-->
<!--head--> …дополнительные теги в <head>, например JSON-LD… <!--/head-->
<section>…</section>
<!--#include final-form-->
```

- `<!--#include имя-->` вставляет `src/partials/имя.html`. Параметры: `only=akpp` — только карточки группы (`data-f`) без кнопок фильтра (страницы АКПП/МКПП/A), `limit=4` — первые 4 карточки (выжимки на главной).
- Блоки `<div class="faq"><details><summary>…` автоматически получают разметку FAQPage, `<nav class="crumbs">` — BreadcrumbList.
- Статьи (JSON-LD `"@type":"Article"`) получают `datePublished`/`dateModified` из git и подпись «Редакция… Обновлено <дата>» под H1; `lastmod` в sitemap — тоже из git (учитываются и вставки страницы). В CI нужен `fetch-depth: 0`.
- В тексте страниц пробелы в числах и перед ₽ при сборке становятся неразрывными.
- canonical всегда указывает на `https://virazh-tomsk.ru` + адрес страницы.

## SEO: факты и структура

- `seo/BRANDCORE.md` — единый источник фактов (цены, сроки, машины, что не публикуем). Любую цифру сначала меняем там, потом на всех страницах.
- `seo/cocoon-map.md` — роли страниц, родители, связи, кандидаты в новые страницы.
- `seo/audit-2026-10-28-drmax.md` и `seo/plan-2026-10-28.md` — разбор по методике DrMax и что осталось.
- Тон текстов официальный: «первый взнос 5 000 ₽, далее 2 000 ₽ за каждое занятие по вождению», без «на старте», «дальше», «по мере езды».

## Выкладка на хостинг virazh-tomsk.ru

1. Собрать `perl tools/build.pl` и проверить `perl tools/check.pl`.
2. Залить **содержимое** `_site` в корень сайта (Apache). Сборка кладёт туда `.htaccess`: https без www, адреса без слэша на конце, 301 с `/uchis-online`, своя страница 404.
3. Проверить несколько старых адресов и PDF, отправить `sitemap.xml` в Яндекс Вебмастер и Google Search Console.

## Предметы в первом экране и 3D-знак

- **Предмет-фото** справа от заголовка внутренней страницы: строка `art: art-ekzameny | подпись` в метаданных страницы (`| sm` в конце — маленький, для «Сведений»). Картинки — `img/art/*.webp`, исходники — `design/art/` (генерация в стиле фото-иконок, промпты в `docs/visuals.md`). Новую картинку: фон убрать `tools/icon-cut.ps1`, затем `py -3 tools/art-webp.py вырезанная.png img/art/имя.webp`.
- **Сцена первого экрана главной** — `img/hero-scene.webp` (компьютер) и `img/hero-scene-m.webp` (телефон, обрезка вокруг машины): белая студия, белый вираж трека с бордовой полосой, Omoda на глянцевом полу. Как сделана и как пересобрать — `docs/visuals.md`, исходники в `design/hero-scene/`.
- **3D-знак «У»** в блоке записи (внизу каждой страницы) поворачивается за курсором, на телефоне — при прокрутке. Модель сделана в Blender (проект 3D Jutsu «Авто-Вираж: знак У учебное ТС»), 25 ракурсов в `design/3d/frames`, собираются в одну картинку `py -3 tools/sprite-sheet.py design/3d/frames img/art/sign-u-sprite.webp 360`. Неподвижный кадр — `img/art/sign-u.webp` (страница «Об автошколе»).

## Чат-помощник

Кнопка «Есть вопрос?» справа внизу (на телефоне — кнопка чата в нижней панели). Помощник отвечает готовыми ответами, без нейросети: ищет ближайший по смыслу вопрос с учётом синонимов, форм слов и опечаток. Всё работает в браузере, переписка никуда не отправляется.

- Ответы — в [bot/answers.md](bot/answers.md): обычный текст, формат описан в начале файла. Добавили или поправили ответ — пересоберите сайт.
- Плюс автоматически подключаются все вопросы из блоков «Частые вопросы» на страницах (ответ из `bot/answers.md` важнее).
- Если ответа нет, помощник предлагает позвонить или записаться. Номер телефона в чате не принимает — отправляет в форму записи.
- Поиск и синонимы — в `assets/js/bot.js` (список `SYN`), сборка базы — в `tools/build.pl`, ссылки в ответах проверяет `tools/check.pl`.

## Версия для слабовидящих

Кнопка с глазом в шапке (ссылка `itemprop="copy"`). Настройки: размер шрифта, цветовая схема (чёрное на белом, белое на чёрном, синяя), картинки вкл/выкл, межбуквенный интервал. Выбор запоминается в браузере. При крупном шрифте страницы выстраиваются в одну колонку без горизонтальной прокрутки.

## Расписание экзаменов

Даты внутренних экзаменов и экзаменов в ГИБДД хранятся в одном файле — [src/partials/exam-dates.html](src/partials/exam-dates.html); блок стоит на главной и на странице `/ekzameny`. Чтобы обновить, поменяйте даты в формате `ДД.ММ.ГГ` (например `27.10.26`) и пересоберите сайт. День недели, «через сколько дней» и пометку «прошёл» браузер посчитает сам.
